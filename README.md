# JorgeSTREAM Broadcast Studio 

A professional web-based broadcast streaming studio with integrated radio player, audio monitoring, and server management capabilities.

## Features

### Broadcast Studio
- **Real-time Audio Monitoring** - Professional VU meters and waveform visualization
- **Server Configuration** - Support for IceCast and ShoutCast protocols
- **Connection Management** - Test and connect to streaming servers
- **Audio Device Selection** - Choose from available microphones and inputs
- **Live Statistics** - Monitor listeners, dropped packets, and latency
- **Dark/Light Theme** - Toggle between themes for comfortable viewing

### Radio Player
- **Global Audio Player** - Music continues playing across all pages
- **20+ Radio Stations** - Curated list of African and international stations
- **Mini Player** - Persistent floating player with playback controls
- **Favorites System** - Save your favorite stations locally
- **Recent Stations** - Track your listening history
- **Search & Filter** - Find stations by name, genre, or country
- **Audio Visualization** - Real-time waveform and level meters
- **Volume Control** - Adjustable volume with visual feedback

### Additional Features
- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Keyboard Shortcuts** - Quick access to common actions
- **Local Storage** - Persists user preferences and favorites
- **Error Handling** - Graceful error recovery and user feedback
